# 失败模式（failure_modes）

本文件枚举 harness 运行中会遇到的非预期情况及处置纪律。核心原则：**证据
存在但自动验收不通过时交人工复核（rc=2），绝不伪造通过结论。**

## 1. env_unavailable（rc=3）

- **被测程序不存在**：`--program` 路径错误或未安装。检查路径。
- **CDP 端口未就绪**：程序未以 `--remote-debugging-port` 启动、被占用、
  或启动缓慢。增大 `--timeout`，确认端口空闲。
- **CDP 连接失败 / 无 page 目标**：程序未真正渲染页面。确认 `--url`
  可达（演示态可用本地/占位 URL，不要依赖真实联网）。

处置：修正参数后重跑对应阶段；不要当作验收失败。

## 2. unverified（rc=2）—— 最常见，需人工复核

- **截图物理尺寸与期望不符**：真实 DPI 与 `content_scale` 推导值有偏差
  （PerMonitorV2 在 >250% 时系统会钳制逻辑 DPI）。证据已落盘，人工核对
  显示器真实缩放与窗口是否最大化。
- **交互验收项不符**：DOM 查询的选择器/属性名与被测程序实现不一致，
  或演示态未正确进入。核对真值清单与被测页实现。
- **截图命名不符约定**：文件名缺少 `dpi`/`逻辑尺寸`/`物理尺寸` 段。

处置：人工打开 `shots/*.png` 与 `artifact_manifest.json` 复核；核对后
更新真值或调整被测程序。不要机械重跑直到"看起来绿"。

## 3. input（rc=4）

- `content_scale` ≤ 0、逻辑窗口尺寸非正、参数格式错、`--set-env` 缺 `=`。

处置：修正参数。

## 4. DPI 相关陷阱

- **只截内容区漏掉 DPI 表现**：必须用整窗截图（含标题栏/边框），否则
  300% 下标题栏文字仍按 100% 渲染会被遗漏。capture_window 默认整窗。
- **逻辑像素 ≠ 物理像素**：CDP `Page.captureScreenshot` 默认返回逻辑
  像素；本 harness 按 `content_scale` 把期望物理尺寸算出来比对。
- **PerMonitorV2 多显示器**：不同显示器 DPI 不同，最大化窗口移动后尺寸
  会变；验收时应固定显示器/缩放并记录。

## 5. 隔离相关风险

- **误用真实账号目录**：`--user-data-dir` / `--data-dir` 指向真实安装
  会污染真实账号。脚本不内置路径，但调用方必须传入运行内独立目录。
- **mock 数据未生效**：被测程序未读取 `VAH_MOCK_DATA_DIR` 环境变量，
  仍加载真实数据。验收前确认演示态确实隔离。

## 6. 自测与复核纪律

- 改任何 scripts 后必须重跑 `python tests/smoke_test.py`。
- 真实链路只用演示/游客态 + 占位 URL 验证，不要依赖真实账号联网。
- 报告结论时列出脚本路径 + 命令 + 结果片段；不许写"已通过"这类无证据
  结论；不能验证的部分停下来报告，而不是声称通过。
